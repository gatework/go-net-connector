# v0.4.0

本版本集中共享清单采集、配置规则与证据所有权，统一应用装配和工作流组织。固定依赖 go-expect v0.4.1。

- `netdisco.FetchHTTP` / `FetchPostgres` 统一来源采集、缓存身份与结果状态。完整清单与刷新/写入错误分别保留，调用方无需重复装配来源和缓存。
- 新增纯配置入口 `config.InventoryEnvironment` / `ValidateInventory`。共用字段定义；高优先级字段按存在性屏蔽环境值，包括 false、null、空列表和替换父节。
- Bootstrap 生成类型化设置；Workflow 发出类型化事件；CLI 与持久化报告共用拓扑呈现。进度和输出失败降低最终状态，保留已确认的步骤和存储回执。
- 规范备份来源证据及清单数据所有权，避免调用方修改保留的状态。设备命令、报告 schema 和 CLI 参数维持既有合同。
- 采用 Expect 的写截止时间修复：设置、更新或清除截止时间失败时退休会话，保留实际写入进度，不自动重放。

清单缓存身份有迁移：升级后先使用 prefer/refresh 从来源刷新，再依赖 cache-only；不能把旧身份缓存当作新身份的完整证据。Go 调用方见 [API 迁移](../api-migration.md)。

发行包包含 Linux/macOS × amd64/arm64 的 netman、tftp-archive、同提交源码、版本与提交身份、第三方许可和 SHA256SUMS。发布使用同提交 CI 产物；本地/CI 验证不代表真实设备或生产部署验收。
