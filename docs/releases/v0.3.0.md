# v0.3.0

本版本增加借用已连接设备的组合操作，供采集和受控变更调用方统一管理会话生命周期。普通 Device 和 WithOperation 的连接策略保持原有契约；依赖仍固定为正式 go-expect v0.4.0。

- `Device.WithBorrowedOperation` 持有整段操作租约，要求设备已连接，禁止隐式连接、重连和命令重放；操作错误与首次清理错误分别返回。
- `Operation.Retire` 可在取消后释放资源，拒绝重入、重复及过期调用。作用域退出保留首次清理失败，不重复退休；显式 `Device.Close` 可以重试失败清理。
- `ExecuteOptions.PreserveSessionOnRejection` 只接受借用作用域内的单命令。仅完整、已同步、编码验证通过的纯设备拒绝可保留连接；取消、超限、观察回调或日志失败仍会退休。
- 被拒绝或未完成的原始响应继续保存在 `Result.Attempts`；它们不会成为 `Result.Steps` 中的已接受命令。调用方处理拒绝后返回 nil 才可继续使用借用会话。
- 最终观察回调取消或 panic 后，即使业务捕获 panic，仍执行资源退休并保留清理结果。

迁移示例及所有权契约见 API migration（见对应版本标签下的 docs/api-migration.md）。发行包包含 Linux/macOS amd64/arm64 的两个命令、同提交源码、许可、版本身份与 SHA256 校验和。测试和 CI 验证不代表真实网络设备或生产部署验收。
