# v0.5.0

本版本新增供网络运维应用复用的回执与配置能力，保留现有设备操作、CLI、报告和归档协议。

- `Result.SingleAccepted(command)` 验证唯一已接受主命令；整体执行错误仍独立处理。`StepResult.Body()` 只从严格验证的响应移除已确认提示符和首行命令回显，保留正文空白与原始 Attempts；备份保真视图不能冒充严格正文。
- `config.ReadFile(ctx, path, missingOK)` 统一普通配置文件读取，限制 16 MiB，拒绝特殊文件，保留可读符号链接和缺失策略。取消后不返回部分内容，原因可通过 errors.Is 识别。
- `config.LoadContext` 贯通 CLI/bootstrap 的取消；旧 Load 保留兼容。`ParseYAMLMapping` 复用严格解析预算并要求显式根映射；旧 ParseYAML 的空/null 语义不变。
- 架构门禁从实际 Go 传递依赖图阻止库倒依赖 CLI/装配层，覆盖嵌套包及负例；AGENTS、架构、迁移与验证说明随源码跟踪。

依赖保持正式 Expect v0.4.1。同步文件系统调用在读取阶段边界检查取消，不承诺中断阻塞 syscall。不自动重放、重连、回滚或保存配置。

调用方式见 API 迁移（见对应版本标签下的 docs/api-migration.md）。发行包使用同提交成功 CI 的不可变制品，覆盖 Linux/macOS × amd64/arm64；本地与 CI 测试不代表生产设备验收。
