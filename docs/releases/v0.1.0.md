# v0.1.0

The first packaged release includes `net-backup`, `net-backup-batch`,
`net-backup-tftp`, `net-topology` and `net-connector-archive` for Linux and macOS
on amd64 and arm64, plus the complete source archive.

- Device sessions support explicit login, password, confirmation and paging rules, cancellation, verified output conversion and retryable resource cleanup.
- Command attempts preserve partial writes, raw responses and completed receipts when later operations fail, without replaying device commands.
- Batch execution uses bounded workers and inventory budgets, with faster HTTP/PostgreSQL field mapping and vendor-specific TFTP completion checks.
- Source builds require Go 1.26 or newer and pin go-expect v0.1.2; the packaged macOS binaries require macOS 13 or newer.

Development API migration: custom authentication hooks now implement
`Authenticated(context.Context) error`; legacy hooks are rejected before login.
Callback signatures, immutable response access and fleet package moves are
documented in [API migration](../api-migration.md).
