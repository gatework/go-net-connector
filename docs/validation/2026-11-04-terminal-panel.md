# 原地进度与清单表格

根因：开始/成功事件直接追加日志，心跳只擦除一行，文本按字符而不是终端显示宽度裁剪。此前测试检查文案存在，没有检查实际屏幕。

行为约束：普通和 verbose 模式都原地刷新；成功只更新统计；异常保留在面板上方；提示期间暂停；停止后不能恢复绘制。非终端无 ANSI，五秒汇总。所有中文帮助保持同步。

实现：Reporter 统一拥有进度与警告输出，使用有界刷新及 Unicode 字素裁剪；表格固定 IP、名称、厂商、型号、状态，异常优先，完整地址按单元格换行；内部视图独立于现有 JSON。

自动验证：千任务屏幕回放，普通/详细模式，异常保留；实际 PTY 40/80/120 列；暂停/停止顺序；中文、emoji、组合字符；IPv6 保留、异常排序、inventory 不连接设备。通过候选源码配对脚本运行 race、shuffle、vet。构建身份与源码摘要保存在 bin/build-manifest.json。

边界：离线验证，不代表真实设备批量验证。窗口缩放按当前终端列宽重绘并清除管理区域；不同终端的历史行重排仍需实际交互使用观察。独立审查工具因鉴权失败未能运行，改为作者复查，重点检查退出恢复、写入失败和提示互斥。
