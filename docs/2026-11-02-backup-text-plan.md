# 备份文本保真与中文操作提示

实施范围：备份专用容错文本视图与原始响应双文件、编码告警与回执、PAN 配置边界、Radware 登录阅读确认、所有面向人的 CLI/文本报告中文化。

约束：普通命令、RunningConfig、拓扑解析保持严格校验；不猜测未知字节；机器字段、状态码、参数与退出码兼容；不写设备配置、不提交或发布。原始旁车按内容哈希命名，先保存原文再原子发布阅读视图，分别记录持久化边界。

验证：真实私有证据脱敏后提取最小回归；分包、分页、UTF-8/GB18030/坏字节、双文件失败、中文离线帮助、PAN 多行引号与前后差异、Radware 受限阅读确认。完成本地全门禁后，只读复测六台历史补齐目标及正常对照，存入独立备份目录。

历史批次只做审计，修正阅读视图生成新文件；缺少原文时不宣称文字语义已确认。日志、报告、测试中均不暴露生产配置或凭据。
